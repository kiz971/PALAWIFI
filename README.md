# PALAWIFI — Made by: Don Genciano

A mobile-friendly landing page prototype for the PALAWIFI voucher portal.

## Included files
- `index.html` — page content
- `styles.css` — white and navy-blue design
- `app.js` — basic front-end form behavior

## Important
This is only the visual/front-end prototype. It does **not** validate vouchers, authenticate users, grant internet access, or enforce the 10-minute / 1-hour / 3-hour time limits.

Those functions require a compatible captive-portal gateway and a secure server-side voucher system. Do not put administrator passwords, router credentials, or secret API keys in these front-end files.

## Preview
